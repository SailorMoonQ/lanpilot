# LanPilot M2 设计文档：第一个可用的 iOS 版本

- 日期：2026-10-08
- 状态：已评审（用户逐节确认），待编写实施计划
- 上位文档：`docs/superpowers/specs/2026-10-07-lanpilot-design.md`（以下简称"总设计"），本文只写 M2 新增或细化的内容；与总设计冲突时以本文为准
- M0 依据：总设计第 9 节；`spike/m0` 分支的 `spikes/m0/ios-results.md`、`spikes/m0/accel/windows-results.md`

## 1. 范围

### 1.1 手机端（iOS）

- 设备发现（系统 API）
- 添加电脑：扫码、系统相机扫码（`lanpilot://` 链接）、粘贴链接、附近的电脑 + 密码、手动输入 IP + 密码
- 启动自动连接上次使用的电脑；顶部设备名弹出切换面板
- 触摸板页（经典三段式）、媒体页、快捷指令页（"即将推出"占位）
- 设置：灵敏度、加速度档位、滚动速度、自然滚动、点击延迟、振动、按键条显示、主题、语言、关于
- 三种主题：原生（跟随系统浅色/深色，默认）、深色沉浸、品牌色（渐变 + 毛玻璃）
- 横竖屏；中英文界面

### 1.2 电脑端与协议（根据 M0 结论）

- 协议新增缩放消息 `Zoom`，电脑端以能力标志 `zoom` 声明支持
- Windows 指针改为绝对坐标注入，绕开系统"提高指针精确度"加速曲线
- 配对邀请过滤代理/VPN 虚拟网卡地址

### 1.3 不在 M2

文本发送、快捷指令功能、Face ID 解锁、Android、TestFlight 发布、Linux 指针加速处理（等 Ubuntu 验证）。

## 2. 界面

### 2.1 主题

三套主题共用同一套组件，只换颜色、背景和控件材质：

| 主题 | 背景 | 触摸板 | 控件 | 强调色 |
|---|---|---|---|---|
| 原生 | 系统分组背景（浅 `#F2F2F7` / 深 `#000000`） | 卡片白 / 深灰，细描边 | 卡片 | 系统蓝 |
| 深色沉浸 | 纯黑 | 近黑 `#0D0D0F`，弱描边，面积略大 | 深灰 | 青色 `#64D2FF` |
| 品牌色 | 紫粉渐变（`#5B4BFF → #8F5BFF → #FF7AA8`） | 半透明白 + 毛玻璃 | 半透明白 | 白 |

深色沉浸与品牌色不随系统浅深色变化。主题在设置中切换，立即生效。

### 2.2 触摸板页（竖屏）

自上而下：状态栏（设备名 + 连接状态圆点 + `▾`；右侧预留键盘按钮位置，M2 不显示）→ 触摸板 → 左右键条（可在设置中隐藏）→ 底部标签栏（触摸板 / 快捷指令 / 媒体）。

横屏：触摸板占满，左右键条竖排在右侧，标签栏变为左侧竖排图标。

非"已连接"状态时，触摸板上覆盖半透明遮罩，显示状态与原因（见 4.5），手势不发送。

### 2.3 启动流程

- 有已配对电脑：直接连接上次使用的电脑并进入触摸板页；约 5 秒仍未连上则自动弹出切换面板
- 无已配对电脑：显示"添加电脑"页

### 2.4 切换面板（点击顶部设备名弹出的底部面板）

已配对电脑列表（名称、在线/离线、系统）、当前项打勾、左滑"取消配对"、底部"添加电脑"。

## 3. 代码结构

```
app/                                   Flutter 工程（iOS 先行，Android 在 M6）
├── rust/                              桥接 crate（独立 workspace，路径依赖 ../../core）
│   └── src/api/                       flutter_rust_bridge v2 暴露给 Dart 的接口
├── ios/Runner/Info.plist              本地网络、Bonjour、相机权限说明；lanpilot:// 链接；120Hz
└── lib/
    ├── bridge/                        生成的 Dart 绑定 + LanPilotClient 抽象接口（便于测试替换）
    ├── connection/                    连接管理（第 4 节）
    ├── discovery/                     NWBrowser 平台通道 + 调 core 校验
    ├── pairing/                       扫码、粘贴、附近电脑 + 密码、手动 IP
    ├── touchpad/                      手势状态机（纯 Dart）+ 触摸板页 + 指针曲线
    ├── media/                         媒体页
    ├── shortcuts/                     "即将推出"占位页
    ├── settings/                      设置页 + 持久化
    ├── theme/                         三套主题
    └── l10n/                          中英文 arb 资源
```

依赖选择：Riverpod（状态）、go_router（路由）、mobile_scanner（扫码）、flutter_rust_bridge v2。桥接 crate 固定 `libc = "=0.2.189"`（M0：0.2.190 在 iOS 上破坏 backtrace）。

### 3.1 Rust 桥接接口

桥接层持有一个长期存在的客户端对象（tokio 运行时 + QUIC 端点 + 当前连接 + 指针手势计数器），所有调用经由它完成。Dart 侧只看到下列接口（名称为设计意图，细节由实施计划确定）：

- 身份：`init(dataDir)`（加载或生成身份；私钥由 Dart 侧存入钥匙串后传入，见 3.3）
- 发现校验：`validateDiscovered(fullname, txt, addrs, port) -> DiscoveredDevice?`（调用 core `DiscoveredDevice::from_resolved`）
- 配对：`pairWithUri(uri)`、`pairWithPassword(addr, password)` → `PairedServer`
- 连接：`connect(serverKey, candidateAddrs) -> SessionInfo`（并发尝试所有候选地址，见 4.2）、`disconnect()`（正常关闭）、`resetEndpoint()`
- 输入：`sendPointer(dx, dy)`、`sendScroll(dx, dy)`、`beginGesture()`、`button(button, down)`、`keyChord(usages)`、`media(action)`、`zoom(steps)`、`unpair()`
- 事件流：连接状态与关闭原因（含关闭码 2/3/4、版本不兼容方向）

指针与滚动按"累计值"发送（总设计 3.6）：桥接层维护当前手势的累计总量和序号，Dart 只传每帧增量。

### 3.2 设备发现

iOS 用 NWBrowser（Swift 平台通道）浏览 `_lanpilot._udp`，把实例名、TXT、地址、端口交给 `validateDiscovered`；只有校验通过的结果进入列表（总设计 3.1；M0：iOS 直接组播需要受限授权）。

### 3.3 本地存储

- 身份私钥、已配对电脑公钥：iOS 钥匙串（仅本设备，不同步）
- 已配对电脑列表（名称、系统、候选地址、上次成功地址、上次使用时间）、设置：App 文档目录 JSON 文件

## 4. 连接管理

### 4.1 状态

`未配对` → `连接中` → `已连接` ⇄ `重新连接中`；失败带原因（4.5）。状态以事件流提供给界面。

### 4.2 地址选择

候选地址 = mDNS 最新地址 ∪ 上次成功地址 ∪ 配对/手动地址。连接前等待 mDNS 最多 1.5 秒，然后对全部候选地址并发发起 `connect_paired`（校验电脑公钥），第一个成功者胜出，其余取消。成功地址记为"上次成功地址"。

### 4.3 前后台与网络

- 进入后台：松开所有按住的按键，正常关闭连接（关闭码 0）
- 回到前台：立即重连，触摸板显示"正在重新连接"
- 网络变化（Wi-Fi 切换）：重连
- 替换连接（切换电脑）：先正常关闭旧连接

### 4.4 本地网络权限（M0）

- 首次真正连接时才创建 QUIC 端点（此时 iOS 弹出授权）
- 连接超时 → 重建端点后重试一次（授权后无需重启 App）
- 安装后从未成功连接且持续超时 → 显示引导页："请在 设置 → 隐私与安全性 → 本地网络 中开启 LanPilot"，提供"打开设置"和"重试"

### 4.5 失败原因与处理

| 原因 | 处理 |
|---|---|
| 连接超时 / 电脑离线 | 自动重试；启动时约 5 秒后弹出切换面板 |
| 关闭码 2（未配对）/ 3（被电脑端移除） | 本地删除该电脑，提示"该电脑已移除此设备，请重新配对" |
| 关闭码 4（本机取消配对后） | 本地删除该电脑 |
| 版本不兼容 | 提示"请更新电脑端 LanPilot"或"请更新 App" |
| 本地网络权限 | 4.4 引导页 |

## 5. 触摸板

### 5.1 手势（纯 Dart 状态机，处理原始触摸事件）

| 手势 | 判定（初始值，集中可调） | 输出 |
|---|---|---|
| 单指滑动 | 移动超过 3pt 进入移动 | 每帧一次指针增量 |
| 单指轻点 | 按下到抬起 < 200ms 且移动 < 8pt | 等待点击延迟（默认 180ms）无第二次按下后，左键按下+抬起（附带手势状态） |
| 轻点后按住拖动 | 点击延迟内再次按下并移动 | 左键按下 → 拖动 → 抬起时左键抬起；前一次点击取消 |
| 双指轻点 | 两指 100ms 内按下、250ms 内抬起，移动 < 8pt | 右键 |
| 三指轻点 | 同上 | 中键 |
| 双指滑动 | 两指同向移动 | 滚动，约 40pt 一格（乘滚动速度）；自然滚动开关取反；松手后惯性滚动，再次触碰立即停止 |
| 双指捏合 | 两指间距变化超过阈值且大于平移 | `Zoom`；电脑端不支持 `zoom` 能力时不识别 |

左右键条：按下即按键按下、抬起即抬起，可配合触摸板拖动；按键条上的触摸不计入触摸板手指。振动：点击轻振，开始拖动振一次。

### 5.2 指针曲线

输出像素 = 手指移动（pt）× 基础倍率 × 灵敏度 × 加速系数(速度)。加速系数在慢速约 1.0，随速度平滑上升，封顶约 2.5；预设"关 / 低 / 中 / 高"。所有常量集中在一个文件，M2 完成后真机调参。

### 5.3 发送节奏

同一帧内的触摸事件合并为一个数据报；Info.plist 设置 `CADisableMinimumFrameDurationOnPhone = true` 以启用 120Hz。

## 6. 协议与电脑端改动

### 6.1 `Zoom`

`ClientMessage.body` 新增 `Zoom zoom = 16`，`message Zoom { float steps = 1; }`（正值放大）。电脑端：Ctrl 按下 → 滚动 `steps` 格 → Ctrl 抬起，`steps` 截断到 ±`MAX_SCROLL_NOTCHES_PER_CALL`；在 Hello 能力中声明 `zoom`。补充黄金样本。

### 6.2 Windows 绝对坐标注入

`move_relative(dx, dy)`：`GetCursorPos` → 加偏移 → 限制在虚拟桌面范围（`GetSystemMetrics` 的 `SM_XVIRTUALSCREEN` 等）→ 归一化到 0..65535 → `SendInput(MOUSEEVENTF_MOVE | MOUSEEVENTF_ABSOLUTE | MOUSEEVENTF_VIRTUALDESK)`。进程声明 Per-Monitor V2 DPI 感知。坐标换算写成纯函数并单元测试（含多显示器负坐标、边界钳制、往返误差 ≤ 1 像素）。

### 6.3 邀请地址过滤

`lan_ipv4_addrs` 排除 `198.18.0.0/15`（基准测试/代理 TUN 常用）以及名称看起来是虚拟网卡/TUN/VPN 的接口（实施计划给出判定规则），保留真实局域网地址。
